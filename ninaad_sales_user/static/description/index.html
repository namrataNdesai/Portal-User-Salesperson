Overview

Portal User Salesperson

By default, Odoo allows only internal users from specific groups to be selected as the Salesperson or Responsible on a record, so Portal users never appear in the dropdown. The Portal User Salesperson module adds Portal users to this selection.

Once installed, Portal users can be selected as Salesperson / Responsible on Contacts, Sale Orders, CRM Leads / Opportunities, Purchase Orders and Inventory Transfers. Internal users stay selectable as before.

The module only changes who can be selected. It does not give portal users any extra access to these records. Access is still controlled by the normal access rights and record rules.

Features

  • Portal users can be selected as Salesperson / Responsible, in addition to the existing internal users.
  • Works on Contacts, Sale Orders, CRM Leads / Opportunities, Purchase Orders and Inventory Transfers.
  • Internal users from the existing groups stay selectable. Nothing is removed.
  • No extra setting is needed. Install the module and the portal users appear in the dropdown.
  • Only changes who can be selected. Access rights and record rules still decide what a portal user can see or edit.

Configuration

STEP 1 — SALES, CRM AND CONTACTS

Open a Sale Order, a CRM Lead / Opportunity or a Contact.

  • Click the Salesperson field. Portal users are listed together with the internal users.
  • Select a portal user to assign the record.
STEP 2 — PURCHASE AND INVENTORY

Open a Purchase Order or an Inventory Transfer.

  • Click the Purchase Representative field (Purchase) or the Responsible field (Inventory).
  • Portal users are listed together with the internal users and can be selected.
STEP 3 — ACCESS RIGHTS

Selecting a portal user does not change what that user can open.

  • Access to Sale, CRM, Purchase and Inventory records is still decided by the existing access rights and record rules.
  • Review them before assigning portal users, so each user sees only what you intend.
